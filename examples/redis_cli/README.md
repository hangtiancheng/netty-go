# redis_cli

A simple redis cli written by [netty-go](https://github.com/yukino-js/netty-go)

### Preview

```bash
connecting redis server ...
connected
192.168.212.212:6379>get name
(empty)
192.168.212.212:6379>set name netty-go
OK
192.168.212.212:6379>get name
netty-go
192.168.212.212:6379>exit
exited
```
