# netty-go examples

Runnable examples for [netty-go](https://github.com/hangtiancheng/netty-go).

Run any example from the repository root, for example:

```bash
go run ./examples/tcp_server
```

## Samples

1. [chat_server](./chat_server) - A simple web-based chatroom
2. [file_server](./file_server) - A simple web-based file browser
3. [https_server](./https_server) - A simple HTTPS server
4. [redis_cli](./redis_cli) - A simple Redis CLI
5. [tcp_server](./tcp_server) - A simple echo server and client
6. [websocket](./websocket) - High-level WebSocket server, client, echo and HTTP upgrade examples
