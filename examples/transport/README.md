An open source transport implementation for [netty-go](https://github.com/yukino-js/netty-go)

## Transport

1. TCP (builtin)
2. KCP (A Fast and Reliable ARQ Protocol)
3. Websocket
4. QUIC (Quick UDP Internet Connections)
5. UDP
6. TLS (Transport Layer Security over Tcp)
